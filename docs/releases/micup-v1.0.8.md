# MicUp 1.0.8

Модифицированная сборка, не официальный релиз первоисточника.

- Подключён выбор Local Monitor / VoIP Playback и сохранение режима после перезапуска.
- Исправлено восстановление предыдущего аудиорежима при остановке.
- VoIP здесь означает воспроизведение MicUp, а не виртуальный микрофон для других приложений. Проверено 8 тестов.

APK подписан ключом разработческой сборки. Версии 1.0.7–1.0.12 используют один ключ и устанавливаются поверх предыдущей версии полной сборки.

Работает только обработка и воспроизведение MicUp. VoIP и Shizuku не подменяют микрофон в WhatsApp/Telegram. Телефонные маршруты и усиление требуют проверки на конкретном устройстве.
