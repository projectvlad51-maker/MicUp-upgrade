# MicUp 1.0.7

Модифицированная сборка, не официальный релиз первоисточника.

- Исправлен возврат крутилок компрессора назад: движение накапливается, новый жест использует актуальное значение.
- Добавлены проверки повторных жестов, пресетов и границ диапазона; восстановлен Gradle Wrapper.
- Проверки при подготовке версии: 3 теста интерфейса; APK собран для ARM64, ARMv7 и x86_64.

[Скачать APK](https://github.com/projectvlad51-maker/MicUp-upgrade/raw/8e825f57964da41ec52da7115126711b0fbfef8e/MicUp-1.0.7-compressor-fix-debug.apk) · [Исходники](https://github.com/projectvlad51-maker/MicUp-upgrade/tree/micup-v1.0.7)

Размер: 21,143,095 байт. SHA-256: `edca8e2f9f30159784dcd1a0e142b6750380215605de8639a8b41ac602ee4f75`.

APK подписан ключом разработческой сборки. Версии 1.0.7–1.0.12 используют один ключ и устанавливаются поверх предыдущей версии полной сборки.

Работает только обработка и воспроизведение MicUp. VoIP и Shizuku не подменяют микрофон в WhatsApp/Telegram. Телефонные маршруты и усиление требуют проверки на конкретном устройстве.
