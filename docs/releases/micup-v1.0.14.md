# MicUp 1.0.14 — возврат к исходному аудиотракту

Переработка по исходному MicUp 1.0.6 и версии 1.0.10, указанной пользователем как последняя рабочая. [Подробное сравнение](https://github.com/projectvlad51-maker/MicUp-upgrade/blob/micup-v1.0.14/docs/AUDIO_BASELINE.md).

- Удалены добавленные в 1.0.13/1.0.1 запрет старта в коммуникационном режиме и автоматическое выключение при конфликте записи. MicUp снова пытается запустить исходный движок, не останавливаясь только из-за работающего звонка.
- Обе версии собирают один нативный движок захвата/обработки и общий код очереди воспроизведения. Нативный выход обнуляется, играет один AudioTrack — как в исходнике.
- Сохранены исправленные крутилки компрессора, полный набор эффектов и плагинов, усиление микрофона, усиление своего выхода, отдельные уровни и подключение Shizuku.
- Восстановлены исходный запрос Oboe Exclusive/LowLatency с VoiceCommunication и запрос аудиофокуса VoIP, как в 1.0.10. Выделение сеанса записи сохранено для системных AEC/NS.
- Проверка микрофона остаётся отдельным сохраняемым переключателем, по умолчанию выключена. Эхоподавление подключается при поддержке телефона. Для локальной проверки используйте наушники.
- Ограничитель пиков из Lite перенесён в общий усилитель обеих версий: сохраняет форму пиков вместо жёсткого обрезания сэмплов. Исправлен повтор старого хвоста буфера при изменении размера аудиоблока в очереди.
- Сохранены тихий статус сервиса, запуск записи по кнопке, прежняя подпись для обновления без потери настроек и отключённая отладка release-APK.

Размер: 15,688,207 байт. SHA-256: `68606d75788400e44c6f12a18e8fd8d0b9cfe6b43cc6e11173ceb3cf374da01e`.

Проверено: 52 теста полной версии, 21 тест Lite, 7 нативных проверок усилителя и 4 проверки Noise Gate/ограничителя. Обе release-сборки собраны для arm64-v8a, armeabi-v7a и x86_64; подписи совпадают с предыдущими APK. В итоговом DEX Lite проверены неизменные имя и сигнатура JNI callback, в библиотеках всех трёх ABI — соответствующая сигнатура. Тесты проверяют запуск Lite при MODE_IN_COMMUNICATION, единственный путь callback → вывод, живые настройки, 10 пресетов без включения эффектов изменения тембра и отсутствие автоматической остановки при смене настроек.

**Граница проверки:** реальный звонок Discord, Telegram или WhatsApp на Pixel 9 Pro с бета-Android в облачной среде не проверен. Android может ограничивать одновременный доступ приложений к записи. Возврат исходного аудиотракта сам по себе не создаёт системный виртуальный микрофон: в исходном коде обработанные сэмплы выводятся через AudioTrack, а не подаются во вход другого приложения. Совместимость реальных звонков не объявляется подтверждённой.

Усиление относится к собственному потоку MicUp; оно не снимает аппаратных пределов динамиков/наушников и не повышает все звуки телефона.
