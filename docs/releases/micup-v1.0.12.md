# MicUp 1.0.12

Модифицированная сборка, не официальный релиз первоисточника.

- Переключатели обработки и воспроизведения приведены к понятной логике; запуск звука выполняется только по нажатию пользователя.
- Добавлено усиление выхода MicUp до +24 дБ через системный LoudnessEnhancer, с явным статусом неподдерживаемых устройств.
- Убраны повторные сигналы уведомлений, дубли обновления статуса и ложный активный статус при неудачном запуске.
- Проверено 36 тестов. Системная подмена микрофона Telegram/WhatsApp не реализована.
