# MicUp: 1.0.6 + компрессор и громкость

Эта сборка создана прямым копированием предоставленного пользователем исходного архива **1.0.6** (`a6e87db3e12cbf3d79d695c1a28d5c2fcaed88a8`). Номер APK — **1.0.16**, чтобы он устанавливался как обновление наших предыдущих полных сборок. Идентификатор приложения остаётся `com.micplugin`.

Изменения ограничены следующим:

- Крутилки компрессора накапливают движение и продолжают регулировку от текущего значения; рекомпозиция больше не возвращает старое значение/обработчик. Исходная отрисовка крутилок сохранена.
- Добавлен регулятор усиления микрофона 0…+36 дБ, с плавным усилением и ограничением пиков при положительном усилении.
- Добавлен регулятор усиления собственного вывода MicUp на динамики/наушники 0…+24 дБ через LoudnessEnhancer своего AudioTrack, когда устройство поддерживает этот эффект. Глобальный аудиосеанс 0 не изменяется. Уровни новых регуляторов сохраняются отдельно.

Оба регулятора изначально стоят на 0 дБ. При нулевом усилении микрофона сэмплы не изменяются, при нулевом усилении вывода AudioEffect не создаётся. Усиление относится к звуку MicUp, а не ко всей музыке/звонкам телефона, и не снимает аппаратных пределов динамиков.

Шумовой гейт (`Noise Gate`) взят без изменений из 1.0.6: уменьшает шум в паузах, настраиваются Threshold/Attack/Release. Если пропадает тихая речь, уменьшите порог или временно выключите гейт для проверки усиления.

Исходные главный экран, настройки, четыре режима, Shizuku/Root-код, разрешения, запуск, уведомления, выбор устройств, маршрутизация, аудиофокус, восстановление потоков и остальные эффекты сохранены. В сборку не включён общий код из новых `app`/`lite`. Работоспособность исходных системных маршрутов или передачи обработанного голоса в Discord этой сборкой не подтверждается; соответствующая функциональность не добавлялась.

## Проверка и сборка

```sh
python3 scripts/check_classic_scope.py
RELEASE_TAG=v1.0.16 ./gradlew :classic:testDebugUnitTest
RELEASE_TAG=v1.0.16 ./gradlew :classic:assembleRelease
g++ -std=c++17 -O3 -ffast-math -Iclassic/src/main/cpp classic/src/test/cpp/MicrophoneBoostTest.cpp -o /tmp/micup-classic-boost-test
/tmp/micup-classic-boost-test
```

Нужны JDK 17, SDK 34, NDK 26.3.11579264, CMake 3.22.1. APK: `classic/build/outputs/apk/release/classic-release.apk`. Для совместимости обновления применяется прежний ключ разработческой сборки; отладка release отключена стандартной конфигурацией AGP. Это не сертификат Google Play.

Проверка области изменений сравнивает все 57 исходных файлов приложения: 48 побайтно совпадают, 9 содержат только разрешённые изменения крутилок/усиления и настройки сборки. Отдельно проверяется неизменность открытия/восстановления потоков и всех исходных алгоритмов эффектов. Новые исполняемые файлы разрешены только для усилителей и их двух настроек; также добавлены лицензионные уведомления.
